## Concrete homepage target

At desktop width, create one coherent above-the-fold composition: a concise, modern sans-serif promise and supporting line; a large, locally relevant human image that occupies real visual space; and a prominent functional search integrated with the hero. Clearly distinguish the medical services and medication pathways. Use a restrained botanical green/forest palette with a warm accent and an original recurring visual motif that communicates connected access to care. Give the search readable labels, location input and a clear action. Keep the synthetic-data disclosure visible. At mobile width, stack the same elements with search accessible without a sprawling hero; preserve legibility, touch targets and functionality. Avoid an empty half-page, a detached receipt graphic, generic icon-card repetition and stock medical clichés. Use appropriate rights-cleared photography reflecting Kenyan patients and care.
